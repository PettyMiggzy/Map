# NOMO: The Mines

Open-world 3D miner for **NOMO — The 10K Gnome** (Robin Hood Chain).
Roam the underground with WASD / arrows (drag on mobile), fixed 3/4 follow-cam.
Stop on a **green node** to dig $NOMO into your haul; stop on a **red candle** and
each swing burns real supply off the chain. Wandering NPC gnomes populate the field.
Self-contained `index.html`.

_Prototype — in-game haul only. Multiplayer mining (shared world) is phase 2 and needs a realtime server._
